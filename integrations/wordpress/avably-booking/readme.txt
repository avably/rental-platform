Embed your Avably rental store in WordPress: catalog, availability calendar and reservation form.

== Description ==

Avably Booking connects your WordPress site to your Avably rental store.
Add the [avably_booking] shortcode or the "Avably Booking" block to any
page to embed the full booking flow: product catalog, availability
calendar and a reservation form with offline payment methods.

All Avably API calls happen server-side — your API key never reaches
the visitor's browser.

== Installation ==

1. Upload the plugin to `wp-content/plugins/` and activate it.
2. Go to Settings → Avably Booking and paste your API key (avbl_…)
   generated in the Avably panel.
3. Add the [avably_booking] shortcode or the Avably Booking block to a page.
