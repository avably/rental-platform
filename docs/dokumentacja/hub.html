04Superpowers i stack

Skille Superpowers (metodyka pracy)

  • brainstorming — pomysł → spec (użyte do specu platformy)

06Jak ta strona rośnie

  • Ta strona (docs/dokumentacja/hub.html) jest master-indeksem — każdy nowy, nietymczasowy materiał dopisujemy do sekcji „Materiały" albo „Dokumenty".
  • Gdy powstaje nowy artefakt HTML (np. galeria design systemu), dodajemy do niego klikalny link i zmieniamy status z „wkrótce" na aktywny.
  • Prompt startowy aktualizujemy, gdy zmienia się stan projektu lub zasady — to on jest „cold boot" dla nowej sesji LLM.
  • Aktualizacja tej strony podlega tym samym zasadom co reszta docs (PR, autor Maciej Godek, zero AI/konkurencji).
